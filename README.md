# موهو - MOHO (Anime Space)

موهو هو مساحة عربية سريعة وهادئة لمشاهدة وتنزيل حلقات أنمي ناروتو شيبودن. تم تصميم الموقع لتوفير تجربة خالية من الإعلانات المزعجة، مع واجهة مستخدم تعتمد على "التصميم الزجاجي" (Glassmorphism) المتجاوب مع جميع الشاشات.

## المميزات الرئيسية
- **مشاهدة مباشرة** لجميع الحلقات (فلر ومانغا).
- **حفظ تلقائي لتقدم المشاهدة:** يمكنك إغلاق المتصفح والعودة لاحقاً لإكمال الحلقة من نفس الدقيقة.
- **تحديد الحلقات المشاهدة تلقائياً:** وضع علامة صح عند مشاهدة أكثر من 90% من الحلقة.
- **تنقل سريع (Next/Prev):** أزرار تفاعلية داخل مشغل الفيديو للانتقال بين الحلقات.
- **فلترة ووضع ليلي متكامل:** البحث الذكي، فلترة حسب نوع الحلقة، وواجهة مصممة لتقليل إجهاد العين.

*(ملاحظة: هذه نسخة الويب الثابتة التي لا تعتمد على خادم داخلي، ولذلك ميزة التحميل المجمّع كحزم ZIP غير مفعلة فيها، وهي حصرية لتطبيقات الويندوز والأندرويد).*

## التقنيات المستخدمة
- HTML5, CSS3, JavaScript (Vanilla)
- تخزين البيانات محلياً (LocalStorage)
- واجهة زجاجية متجاوبة (Responsive Glassmorphism)
